# Code of conduct

## Our standard

This project is a technical engineering collaboration. We expect precise, respectful, evidence-based communication — the same standard we apply to engineering claims.

## Expected behavior

- Treat other contributors as experienced colleagues; disagree with evidence, not with people.
- Separate observation from hypothesis; label uncertainty explicitly.
- Review code and documentation with the intent to improve correctness, not to win an argument.
- Respect the project's safety rules: no unsafe changes, no fabricated results, no history rewrite.
- Use inclusive, professional language in issues, reviews, commits, and documentation.

## Unacceptable behavior

- Harassment, personal attacks, discriminatory language, or intimidation.
- Publishing private information or credentials.
- Deliberately misrepresenting evidence, results, or approvals.
- Attempting to bypass approval gates or alter historical records.

## Scope

Applies to all project spaces: repository, issues, PRs, coordination files, and discussions about the project.

## Enforcement

Report unacceptable behavior privately to the maintainers as described in `SECURITY.md` (mark the report as a conduct concern). Maintainers may remove content, restrict participation, or block accounts. Enforcement decisions are made by the project owner.
