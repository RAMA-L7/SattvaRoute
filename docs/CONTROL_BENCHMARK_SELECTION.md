# T-PNR-001 — Control Benchmark Selection Record

## Requirement

A small public ORFS-compatible design with a hard macro and complete collateral, ending at routing, parasitic extraction and final timing reports. The OpenFinRAM/SattvaRoute macro case is preserved unchanged as an unresolved DRT-0073 regression/research case.

## Evaluation (all VERIFIED from local pinned ORFS `25b6429c1644a8682852646bebf19ff164402c76`)

| Candidate | Collateral | Result |
|---|---|---|
| `asap7/riscv32i` + platform `fakeram7_256x32` | LEF, NLDM LIB, behavioral Verilog, SDC in-tree | Synth blocked by Yosys 0.33/ASAP7 Liberty incompatibility. Failed feasibility evidence preserved in `runs/orfs_baseline_riscv32i_control_20261125T135901603871963Z_3541`. |
| `asap7/riscv32i-mock-sram/fakeram7_256x32` | Small mock Verilog + platform views | Same ASAP7/Yosys blocker. Evidence: `runs/orfs_baseline_fakeram_control_20261125T140125244511383Z_4214`. |
| `sky130hd/chameleon` | LEF+GDS shipped, LIB not found, 44.6 MB macro, 4 macros | Too large/incomplete for this milestone. Not attempted. |
| `gf180/uart-blocks`, `asap7/aes-block` | Views generated by extra BLOCKS flow | Extra preliminary flow; not first choice. |
| **Nangate45 + platform `fakeram45_64x32` wrapper** | LEF + LIB + generated synthesis blackbox stub, ORFS platform complete | Selected. Nangate45 Liberty reads correctly in Yosys 0.33; ABC maps successfully; one hard macro instance; small runtime. |

## Selected design

- **Path:** `benchmark/design/nangate_macro_control/`
- **Platform:** Nangate45, pinned ORFS `25b6429c1644a8682852646bebf19ff164402c76`
- **Macro:** platform `fakeram45_64x32` (upstream FakeRAM collateral; LEF + NLDM LIB under `flow/platforms/nangate45/{lef,lib}`)
- **RTL:** `rtl/sattva_macro_top.v` (thin pass-through wrapper instantiating the macro) and `rtl/fakeram45_64x32_bb.v` (generated synthesis blackbox interface only — **not a memory compiler**, no macro geometry or timing content invented)
- **Prepared netlist:** `netlist/sattva_macro_top_synth.v` with `netlist/synth_provenance.txt`; PnR starts from this cached netlist via `SYNTH_NETLIST_FILES`, so recovery never re-synthesizes.
- **SDC:** locally declared 1000 ps clock, 10% IO delays; no target relaxation after results
- **Source URLs:** ORFS repo `https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts`; ASAP7/Nangate platform data licenses are recorded in `flow/platforms/*` and ORFS `LICENSE_BUILD_RUN_SCRIPTS` (BSD 3-Clause for build/run scripts). Nangate45 platform data license: vendor/PDK terms as shipped in the pinned revision.
- **Resource expectation:** small (one macro, pass-through logic); prior tiny ASAP7 stages ran in seconds to ~30 s.

## Known limitations

- Macro Liberty is a FakeRAM/abstract model, not silicon-characterized SRAM.
- The generated blackbox is a synthesis placeholder; macro LEF/LIB come from the pinned platform unchanged.
- Yosys compatibility gate `SATTVA_YOSYS_COMPAT=1` skips one unsupported annotation read in the execution mirror; no design rule, SDC target or technology data is relaxed.
- GDS export and external DRC/LVS signoff are outside scope.

## Acceptance criterion

The control run must reach routing, parasitic extraction and final timing reports. Both RC and engineering verdict are recorded from real artifacts. If this candidate fails, the failure is preserved as feasibility evidence and the acceptance item remains open rather than being masked by offline PASS counts.
