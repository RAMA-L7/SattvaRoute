# Target users & beneficiaries

Not claiming quantified productivity/cost/accuracy gains.

## Physical-design engineers
Need failure diagnosis, constraint investigation, routing failure analysis, evidence correlation, safe corrective actions, reduced repetitive debugging.
**Benefit**: traceable evidence, narrow proposals, no unsafe change.

## VLSI implementation engineers
Need reproducible runs, dependency validation, stage-aware recovery, controlled config changes, artifact integrity.
**Benefit**: manifest v2, fingerprinting, isolated attempts, honest verdicts.

## CAD / EDA infrastructure teams
Need run reproducibility, workflow reliability, tool failure classification, config auditing, dependency management.
**Benefit**: pinned revision + local patches + tool hashes, preflight, no silent drift.

## Research engineers
Need controlled experiments, diagnosis benchmarks, recovery evaluation, evidence-grounded research, repeatable conditions.
**Benefit**: frozen eval v2, held-out protocol, preserved history, reproducible benchmark.

## AI & EDA researchers
Need grounded tasks, evaluation methodology, structured evidence, safe agent workflows, measurable diagnosis/recovery.
**Benefit**: separation of deterministic vs model, no leakage, honest live-AI limits, threat model.

## Engineering organizations
Potential: better auditability, lower debugging overhead, safer automation, reproducible workflows, transparent failure analysis.
**Not** claiming measured outcomes.
